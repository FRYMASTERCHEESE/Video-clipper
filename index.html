Google Cloud setup

  1. Create or open a Google Cloud project.
  2. Enable YouTube Data API v3 and YouTube Analytics API.
  3. Create an OAuth 2.0 Client ID → Web application.
  4. Add https://frymastercheese.github.io as an Authorized JavaScript origin.
  5. Paste the Client ID into the box on the left and save.
  6. Optional: create a restricted API key for Creative Commons search without logging in.

For safety, this build never asks for your Google password or a client secret. Google handles sign-in directly.

Important limits and channel safety

ClipFree does not add a watermark or application-level clip counter. Browser memory, CPU/GPU speed, source-video size, API quotas and YouTube account/API restrictions still create practical limits. No tool can guarantee subscribers, views or watch hours. This build is designed to improve workflow and use your real channel data, not fake engagement.

For reused material, Creative Commons licensing and attribution are only part of the picture. Copyright, commercial-use rights and YouTube's reused/inauthentic-content monetization rules can still apply. Add substantial original commentary, editing or value instead of simply reposting another creator's video.
