Designed for privacy and zero paid-AI bills

Speech recognition and video processing are designed to run in the browser using open-source WebAssembly/WebGPU tools. There are no paid AI API keys in this build. The app itself does not impose a clip-count limit, although device memory, CPU/GPU speed, source-video size, browser support and free-host bandwidth still create practical limits.
