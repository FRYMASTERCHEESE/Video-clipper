ClipFree Mobile Connect + Analytics v12
=======================================

NO POWERSHELL. MOBILE ONLY.

Replace ONE file in your GitHub repository:
  compliance-demo-v11.js

Repository:
  FRYMASTERCHEESE/Video-clipper

On your phone:
1. Open the Video-clipper repository on GitHub.
2. Upload/replace compliance-demo-v11.js with the file in this ZIP.
3. Commit the change to main.
4. Wait a minute for GitHub Pages, then fully close old coreyvibe.org tabs.
5. Reopen:
   https://coreyvibe.org/?audit=1

What you should see:
- A separate "YouTube Connection + Analytics" card.
- Button: "Connect YouTube + Load Analytics" or "Refresh YouTube + Analytics".
- Views, estimated watch hours, average view duration and net subscribers.
- Pressing that button DOES NOT download footage, generate a Short or upload anything.

For the YouTube reviewer recording:
1. Tap Connect/Refresh YouTube + Analytics.
2. Hold the analytics numbers on screen for 5–10 seconds.
3. Then use the audit setup button for 1 Private 10-second Short.
4. Show source/rights, generated metadata, real YouTube video ID, then YouTube Studio.

This keeps the existing v11 compliance panel and adds the separate mobile analytics control.
