What the new card shows:
- Official YouTube videos.insert default bucket: 100 calls/day.
- REAL number of videos uploaded to the connected YouTube channel today.
  This is fetched directly from the authorized YouTube Data API.
- REAL videos.insert calls ClipFree has observed on this browser today.
- Tracked API calls remaining on this browser.
- Whether YouTube actually returned uploadLimitExceeded (channel daily cap).
- Whether Google actually returned quotaExceeded/dailyLimitExceeded.

IMPORTANT:
YouTube has TWO different limits:
1. Google Cloud / YouTube Data API videos.insert quota.
2. A separate YouTube CHANNEL daily upload limit.

YouTube does NOT expose a "remaining channel uploads" number through the API.
ClipFree therefore will not fake or guess that hidden number. If YouTube returns
uploadLimitExceeded, the card immediately reports 0 remaining for the channel.

The 100/day API bucket resets at midnight Pacific Time.
