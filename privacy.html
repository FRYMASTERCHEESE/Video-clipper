Privacy Policy

Last updated: 9 October 2026.

ClipFree AI is a browser-based media workflow tool. When a user chooses to connect YouTube, ClipFree AI uses YouTube API Services and Google OAuth. The current production build is a static website and does not operate its own user account database or backend database for Google/YouTube API Data.

Google / YouTube user information and API Data we access

After the user connects a Google/YouTube account and grants permission, ClipFree AI may access:

  • Channel identity and metadata: channel ID, title/name, description/branding information, public channel statistics and uploads-playlist identifier.
  • Video data: video IDs, titles, descriptions, tags, privacy status, duration, thumbnails, captions-related information, upload/processing information and video statistics.
  • Playlist data: playlists and playlist items needed for visible playlist features.
  • YouTube Analytics data: reports used by the visible analytics dashboard, such as views, watch time, average view duration and subscriber movement.
  • OAuth authorization data: the OAuth access token supplied by Google. ClipFree AI does not receive or store the user's Google Account password.

The current production build requests youtube.force-ssl for creator/upload/channel actions and yt-analytics.readonly for the visible analytics dashboard.

How we collect and use that information

ClipFree AI obtains this information directly from Google/YouTube APIs only after the user connects YouTube and grants permission. It is used only for user-facing features the user requests, including displaying the connected channel, recent videos, playlists and analytics; preparing metadata the user can review; uploading videos and creator assets; and carrying out channel, caption, thumbnail or playlist actions initiated by the user.

ClipFree AI does not sell Google user data, use it for advertising or ad targeting, determine creditworthiness, perform surveillance or data brokerage, or use Google user data to train generalized or non-personalized AI/ML models.

Where Google / YouTube API Data is stored

  • OAuth access tokens: held in browser page memory for the active session only; not written to localStorage or a ClipFree AI server database.
  • Channel, video, playlist and analytics API Data: held in browser page memory while the site is open; not persisted in a ClipFree AI backend database.
  • Local settings: OAuth Client ID, optional YouTube API key and selected settings may be stored in browser localStorage. These are not OAuth access tokens or YouTube Analytics API Data.

API Data refresh / update / deletion frequency

ClipFree AI refreshes connected YouTube API Data when the user connects YouTube, when the user presses visible Refresh / Load controls, and after a successful upload so the page can reflect updated channel state. The current implementation normally schedules that post-upload refresh about 12 seconds after the upload; if an upload job is still active, the refresh is deferred in short intervals until the job is idle.

ClipFree AI does not run a server-side background process that continuously stores or refreshes YouTube API Data after the browser session ends.

In-memory YouTube API Data is deleted from page state when the user disconnects YouTube and is also lost when the page/session closes or reloads. Local setup values remain only until the user selects Clear saved settings or clears the site's browser data.

Device, browser, cookies and similar technologies

ClipFree AI may access ordinary browser/device information needed to run the application, such as browser capabilities, language, screen/media capabilities, WebAssembly/Web Worker support and approximate device-memory capability used for performance decisions. The site also uses browser localStorage for local settings and workflow state.

When the browser requests the ClipFree AI website, Google/YouTube APIs, content-delivery libraries or reusable-media sources, those services necessarily receive ordinary web-request information such as the user's IP address, browser/user-agent headers, request time and requested URL. Those providers handle that information under their own privacy policies.

ClipFree AI does not operate its own advertising tracker and does not intentionally set advertising or cross-site tracking cookies. Google or other third-party services contacted by the browser may use cookies or similar technologies according to their own policies.

Sharing and disclosure

ClipFree AI does not sell, rent or disclose Google user data to advertisers, data brokers, information resellers or unrelated third parties.

  • Google and YouTube: the browser exchanges authorized data directly with Google/YouTube as necessary to perform the feature requested by the user.
  • No separate ClipFree AI backend: the current production build does not operate a server that receives or stores OAuth access tokens or YouTube Analytics reports.
  • Legal/security requirements: information may be disclosed only when required by applicable law/legal process or reasonably necessary to investigate fraud, abuse or a security threat.

Revoking ClipFree AI access and deleting stored data

The user may revoke access using the visible Disconnect YouTube control. ClipFree AI clears connected channel/video/analytics data from page state and, when an OAuth token is available, requests token revocation through Google's OAuth library.

The user may also revoke access from Google Account third-party connections.

To delete local ClipFree AI setup data, use Clear saved settings or clear the site's browser storage. Closing/reloading the page deletes API Data held only in page memory. Deleting ClipFree AI browser data does not delete videos or content stored by YouTube; YouTube-hosted content must be deleted through YouTube or another authorized client that supports that action.

Security safeguards

  • HTTPS/TLS is used for the website and communications with Google/YouTube API Services.
  • Google OAuth 2.0 handles authentication and consent; ClipFree AI never asks for the user's Google Account password.
  • OAuth access tokens stay in active page memory and are not stored in localStorage.
  • The public browser application does not embed a Google OAuth client secret.
  • Permissions are limited to the scopes required by the visible features described in this policy.

Limited Use disclosure

ClipFree AI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Videos, media and upload metadata

Local media processing is performed in the browser. Before a finished video is uploaded to YouTube, the user is shown the finished Short and can review/edit the title, description and choose Private, Unlisted or Public. The media and approved metadata are then sent directly from the user's browser to the YouTube APIs.

Your choices and consent

Google/YouTube access occurs only after the user chooses to connect and grants OAuth permission. Write actions are initiated by the user. The current recovery workflow requires the user to review the finished Short and approve its metadata before upload proceeds.

Google and YouTube policies

Google's handling of information is described in the Google Privacy Policy. Use of YouTube is subject to the YouTube Terms of Service.
