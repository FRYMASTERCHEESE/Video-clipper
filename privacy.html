Privacy Policy

Last updated: 24 September 2026.

ClipFree AI is a browser-based media workflow tool that uses YouTube API Services when you choose to connect a YouTube channel. Video clipping, transcription and most media processing are performed on your device in your browser. This GitHub Pages build does not operate its own account database or upload server.

YouTube API Services and Google data

ClipFree AI uses YouTube API Services. When you connect YouTube, Google handles sign-in and provides a temporary OAuth access token. ClipFree AI does not ask for or store your Google password. The token is kept in page memory for the active browser session and is used only for YouTube API requests needed for features you initiate or enable.

The app may access your connected channel information, uploaded-video metadata, playlists and YouTube Analytics reports, and may perform write actions you explicitly initiate or enable, such as uploading videos, captions and thumbnails or adding a video to a playlist.

The current production build requests two OAuth scopes: https://www.googleapis.com/auth/youtube.force-ssl for the visible YouTube creator/upload/channel features, and https://www.googleapis.com/auth/yt-analytics.readonly for the visible analytics dashboard. ClipFree AI does not request the separate youtube.readonly scope because the broader creator scope already covers the YouTube account access required by these features.

The Google OAuth Client ID and optional public YouTube API key you enter may be stored in this browser's localStorage so setup persists on this device. ClipFree AI does not store a Google client secret in the website.

How YouTube data is used

YouTube data is used to show your connected channel, recent videos, analytics and playlists; generate channel/video optimization suggestions; upload media and related metadata that you instruct ClipFree AI to publish; and add uploaded videos to playlists when you select or enable that option. ClipFree AI does not sell YouTube user data or use it for advertising, surveillance or unrelated purposes.

Limited Use disclosure: ClipFree AI's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

ClipFree AI does not transfer Google user data to advertising platforms, data brokers or information resellers, and does not use Google user data to train generalized or personalized AI models. In this static browser build, Google user data is processed for the user-facing YouTube features described in the app and is not made available for routine human reading by ClipFree AI operators.

Videos and media

Local video files are processed in your browser. If you use reusable-media discovery, your browser may request files and metadata from Wikimedia Commons. If you upload to YouTube, the finished media and metadata are sent directly from your browser to Google's YouTube APIs.

Storage, revocation and deletion

This static build does not persist channel analytics or OAuth access tokens on a ClipFree server. Authorized YouTube data displayed in the interface is refreshed from YouTube and is cleared when the page/session state is cleared. Browser-saved setup values can be removed with the Clear saved settings control or by clearing this site's browser data.

You can disconnect YouTube at any time using the Disconnect control. ClipFree AI then revokes the current token through Google's authorization library when available and clears the YouTube data held in page state. You can also revoke ClipFree AI from your Google account permissions.

Deleting locally stored ClipFree settings does not delete videos or other data stored by YouTube. To delete data/content stored by YouTube, use YouTube or an authorized API client that supports that action.

Your choices and consent

ClipFree AI identifies the connected YouTube channel and shows the visibility setting used for uploads. Upload/write actions are performed only after you initiate or enable the workflow and confirm that you have the rights to upload the content and that it complies with YouTube's Community Guidelines.

Third-party services

The app can load libraries or data from Google, YouTube, Wikimedia Commons, jsDelivr, unpkg, Hugging Face and related content-delivery services. Those services may receive normal web request information such as IP address and browser headers under their own privacy policies.

Google and YouTube policies

Google's handling of information is described in the Google Privacy Policy. Use of YouTube is subject to the YouTube Terms of Service.

Donation links

The optional charity button only opens the external charity or fundraiser URL configured by the site owner on that browser. ClipFree AI does not process, collect or hold donation payments.

Contact and data requests

This current build is a static self-hosted tool, so you control the browser data on your device. Use Disconnect and Clear saved settings to revoke access and remove local setup data. If ClipFree AI later adds a hosted account or backend, this policy will be updated with the applicable contact information and hosted-data deletion process before that service is offered.
