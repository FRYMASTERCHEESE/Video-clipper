WHAT THIS UPDATE DOES

VISIBLE WEBSITE
- Removes the duplicate 20-Short card/button.
- Removes duplicate visible navigation/wizard sections.
- Keeps ONE clean Shorts creator screen.
- Keeps the old engine controls hidden in the DOM only because the upload/render
  code still needs them.

DIFFERENT VIDEO EVERY TIME
- "Different animals — no repeats" is now the default topic.
- A large rotating wildlife query bank covers mammals, birds, reptiles, marine
  life, amphibians, insects and habitats.
- Each Short uses one source video only.
- Each Short in Variety mode searches a different wildlife query.
- The query cursor rotates between runs so the next batch starts somewhere new.

SKIPS VIDEOS YOU ALREADY USED
- ClipFree scans up to 500 of your uploaded YouTube video descriptions.
- Wikimedia Commons / Internet Archive source URLs found in those descriptions
  are blacklisted.
- ClipFree also stores its own confirmed source history in the browser.
- A source is added to history ONLY after YouTube returns a real video ID.
- The local source history keeps up to 5,000 used source keys.

"THOUSANDS"
This does NOT try to download thousands of videos to your phone at once.
It searches large Public Domain/CC0 repositories through a rotating bank of
wildlife searches and keeps moving to unused sources over time. This is much
safer and faster on mobile and gives the system access to a very large pool
without filling memory or reusing the same clips.

RIGHTS
The existing strict Public Domain / CC0 filter remains in place.
No code can guarantee that every source frame is visually free of embedded
logos/text, but ClipFree itself adds no watermark.
