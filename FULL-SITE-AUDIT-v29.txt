REAL BUGS FOUND
1. Older category-page code can re-add batch choices 11–20 after v28 removes them.
   v29 permanently removes >10 options with a MutationObserver.

2. v27's 7-second outer source timeout can expire before the federated provider
   stack naturally finishes, creating false "no source" failures.
   v29 changes the bounded source window to 18 seconds.

3. The v28 real-video-ID grace code can read ClipFreeTransferredUploadState.lastVideoId,
   but the legacy transfer tracker did not populate that field.
   v29 now synchronizes it on every real YouTube transfer event.

4. index.html still uses old cache-version query strings even though newer files
   have been uploaded. That can allow mobile Chrome to temporarily mix old/new JS.
   Direct GitHub writes are blocked by the current GitHub integration permission,
   so v29 cannot safely replace index.html automatically from ChatGPT.
   The runtime hotfix itself remains safe and reviewer-compatible.
